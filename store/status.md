## Google Play — ГОТОВО, чака Google

**Блокирано е на едно нещо:** Google проверява самоличността на
собственика на акаунта (`neshovska`, Personal account). Документите са
качени, чака се имейл. Отнема до няколко дни.

Редът е строг и нищо не може да се прескочи:

```
самоличност (Google) → телефон (2 мин, ти) → Create app
```

Бутонът "Create app" стои заключен с надпис *"Complete account
verifications to create new apps"*, а потвърждаването на телефона също е
сиво, докато самоличността не мине.

### Проверено на реално устройство (Samsung Galaxy A17, Android 16)

- Приложението тръгва нативно.
- **Напомнянията звънят при НАПЪЛНО затворен ап** — последното
  непроверено нещо в проекта.
- Баджът върху иконата се изчиства при отваряне на приложението
  (виж `clearDeliveredNativeNotifications()`).

### Когато дойде имейлът

1. Потвърди телефона (Developer account → Account details)
2. Create app → `iForget`, български, App, Free
3. Store listing — копирай от `store/store-listing-texts.md`
4. Data safety — ⚠️ **не пропускай здравната информация** (месечния
   цикъл, `cycleData`). Пропуснато деклариране е причина за сваляне на
   приложението после, не при първото ревю.
5. Content rating — кратък въпросник
6. Качи `.aab` → Rollout

⚠️ **Преди качване: `git pull` и пресглоби.** Файлът на диска остарява при
всяка промяна в кода:

```
cd ~/iforget && git pull origin main && npm run sync
cd android && ./gradlew bundleRelease
```

Провери, че поправките наистина са ВЪТРЕ в пакета, не само в repo-то:

```
unzip -p app/build/outputs/bundle/release/app-release.aab \
  base/assets/public/index.html | grep -c clearDeliveredNativeNotifications
```

Това е реален капан — веднъж вече беше инсталиран APK без поправка,
защото `npm run sync` копира ЛОКАЛНИЯ файл, а `git pull` беше пропуснат.
Симптомът е коварен: build-ът минава, приложението работи, само
поправката липсва.

⚠️ **Провери в Play Console дали важи изискване за затворен тест** с
тестери преди публично пускане (раздел Testing). За нови лични акаунти
такова правило беше въведено; числата се менят. Ако важи, тръгва ПЪРВО —
върви по календар и добавя седмици.

## App Store — кодът се компилира, останалото чака $99

**Локален build е невъзможен.** MacBook Air 2015 е спрян на macOS
Monterey → максимум Xcode 14.2 → Capacitor 8 иска Xcode 15+. Няма
безплатно решение на тази машина.

**✅ Проверено, че се компилира** (22.08.2026): `.github/workflows/
ios-build.yml` сглоби за симулатор в GitHub Actions —
`** BUILD SUCCEEDED **`. Пуска се ръчно от Actions → "iOS build
(проверка)" → Run workflow. Безплатно: симулаторът не иска сертификати, а
repo-то е публично.

**Какво остава:**
- Apple Developer $99/година — без него нищо не стига до iPhone.
- Сертификати в GitHub Secrets + разширяване на workflow-а до подписан
  build и качване в App Store Connect.
- TestFlight за реален тест на iPhone (единственият път, защото Xcode
  локално е недостъпен).

**НЕПРОВЕРЕНО:** дали приложението работи на iOS. Компилация ≠ работа.
Напомнянията там са виждали само браузър; ограничението е 64 чакащи
известия, затова кодът насрочва първите 50.

**Междувременно iPhone потребителите не са без нищо** — iforget.eu се
добавя на Home Screen като PWA и изглежда почти като приложение. Липсват
само напомнянията при затворен ап.
